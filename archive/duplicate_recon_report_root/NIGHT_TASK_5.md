## 모듈 1 — 광고(Ads) 영역 완전 제거

전 화면에서 광고 배너를 제거하고 그 공간을 회수한다.

**작업:**
1. `grep -rni "ads\|admob\|admob\|banner" lib/` 로 광고 위젯/패키지 위치 전수 파악.
2. 첫 화면, 목적지 선택, 경로 표시 화면 하단의 "Ads" 영역 위젯을 제거.
3. 광고가 차지하던 레이아웃 공간(여백/높이)도 함께 제거해 하단이 비지 않게.
4. `pubspec.yaml`에 광고 전용 패키지가 있으면 의존성도 제거(있을 때만). 없으면 패스.

**완료 기준:**
- [ ] 첫 화면 / 목적지 선택 / 경로 표시 화면 어디에도 "Ads" 영역 없음
- [ ] 광고가 있던 자리에 빈 띠/여백이 남지 않음
- [ ] `flutter analyze` → 0 issues
- [ ] 커밋: `git commit -m "feat(ui): 광고 영역 전체 제거"`

## 모듈 2 — 야간모드 폐지 → 주간 단일 사양 고정

현재 **시간대(시각)에 따라 지도 타일 + UI 테마가 다크로 전환**되는 구조로 보인다(06시 캡처 시 다크, 이후 라이트). 이 분기를 죽이고 **항상 주간(라이트)** 으로 고정한다.

**작업 (조사 먼저):**
1. 먼저 분기 지점을 찾는다:
   ```bash
   grep -rni "dark\|night\|isNight\|theme\|brightness\|sunrise\|sunset\|일출\|일몰" lib/
   ```
2. 시간대 → 테마/지도스타일 전환 로직을 찾으면, **항상 주간 값을 반환하도록 하드와이어** (분기 자체를 제거하지 말고 day로 고정 → 되돌리기 쉽게).
   - Flutter `ThemeData` / `ThemeMode` → `ThemeMode.light` 고정
   - 지도 타일 URL이 주간/야간 두 종류면 → 주간 URL 고정
3. 일출/일몰 세로 다이얼 위젯: **위젯 자체는 건드리지 말고**, 위 분기 고정의 결과로 주간 표시가 나오면 OK. 내부 재설계·삭제 금지.

**완료 기준:**
- [ ] 어떤 시각에 실행해도 지도·UI가 주간(라이트)으로 뜸
- [ ] 다이얼 위젯이 사라지거나 크래시 나지 않음
- [ ] `flutter analyze` → 0 issues
- [ ] 커밋: `git commit -m "feat(ui): 야간모드 폐지, 주간 단일 사양 고정"`

> 조사 결과 분기 지점이 모호하거나 변경 범위가 3개 파일을 넘으면, **여기서 멈추고** MORNING_REPORT에 "분기 구조"를 기록만 하고 모듈 3으로 넘어갈 것. (광범위 수정 = 회귀 위험)

## 모듈 3 — 첫 화면 버튼/safe-area 정리

대상 파일: 첫 화면(메모리상 `lib/features/map/presentation/main_map_screen.dart`).

**작업:**
1. **현위치 버튼 ↔ 줌(+/−) 버튼 간격**: 두 그룹 사이 간격을 균일하게, 그리고 현재보다 더 띄운다 (예: 사이 여백 16~24px). 줌 버튼끼리 간격도 일정하게.
2. **상태표시줄 침범 제거**: 지도/상단 영역이 상태표시줄까지 올라오지 않도록 `SafeArea`로 감싸거나 상단 패딩 적용. 지도 자체는 풀블리드여도 되지만, **상단 컨트롤바(로고/아이콘들)** 가 상태표시줄에 가리지 않게.

**완료 기준:**
- [ ] 현위치 버튼과 줌 버튼 사이 간격이 시각적으로 충분히 벌어짐
- [ ] 상단 아이콘바가 상태표시줄에 가리지 않음
- [ ] `flutter analyze` → 0 issues
- [ ] 커밋: `git commit -m "fix(ui): 첫 화면 버튼 간격·safe-area 정리"`
