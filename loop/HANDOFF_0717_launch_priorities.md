이 문서는 2026-07-17 세션에서 정리한 "앱 출시까지 남은 과제" 우선순위 보고에 사용자가

항목은 전부 미착수(개발 안 함)** — 다음 세션이 착수 전 우선순위 판단용으로 참고할 것.

기존 소스:

**신규 추가 (2026-07-17 사용자 요청, 미착수)**:

     위에 가중치 값만 조정하는 튜닝 작업에 가까울 것으로 보임(추정, 미검증).

4. **모든 TTS 안내 멘트 CSV export 기능**

**신규 추가 (2026-07-17 사용자 요청, 미착수)**:

5. **주소 검색 기능** — 검색창에 주소를 입력하면 해당 위치로 지도 포인터 이동.
   - 기존 13-1 검색창(`main_map_screen.dart`)은 data.go.kr 상가 DB 기반 **상호명 검색**이라
     이것과는 다른 기능 — 임의 주소 문자열을 좌표로 바꾸는 지오코딩이 별도로 필요할
     가능성이 높음(도로명주소 API, Nominatim류, 또는 Valhalla 자체 기능 여부는 미조사).
     착수 전 지오코딩 소스 조사가 선행돼야 할 것으로 보임.

6. **즐겨찾기 기능 보강** — 집/자주 가는 곳을 POI로 등록.
   - 기존 `places_service.dart`(즐겨찾기·최근장소 로컬 저장)가 이미 존재하나 UI 흐름은
     이번 요청 스펙과 다를 수 있음(미확인). 요청 스펙:
     - POI 탭 시 나오는 카드에 "즐겨찾기에 추가" 버튼 추가
     - 탭하면 제목 '즐겨찾기'인 새 카드가 뜨고 이름 입력받음
     - 저장된 즐겨찾기는 지도 위 POI 아이콘을 별(star) 또는 상응 아이콘으로 표시
   - 로그인 없이 로컬 저장 기준일 것으로 보임 (RELEASE_ROADMAP 13-6 로그인 보류 방침과 일치).

7. **설정 페이지 다시 만들기** — 전면 재구축.
   - RELEASE_ROADMAP 13-4(도로 선호도/내비뷰 설정), 13-7(다크모드, 현재 11번에 흡수 대기),
     13-8(오프라인 지도, 12번 후속으로 재분류 검토)과 스코프가 겹칠 가능성 높음 — 착수
     세션에서 "재구축"이 이 세 항목을 포함/대체하는 것인지 사용자와 범위 확인 필요.

8. **다크모드 설정**
   - RELEASE_ROADMAP 13-7과 동일 항목, 현재 "11번(토큰 리팩터, 8번 팔레트 확정 후 착수)에
     흡수" 방침으로 DEFERRED 상태 — 이번 요청으로 우선순위가 올라간 것으로 이해되나,
     8번(브랜드 팔레트 확정)이 여전히 선행조건인지는 다음 세션에서 재확인 필요.
