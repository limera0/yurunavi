## Phase 0 — 데이터 변환 (결정 확정)

원본 데이터(1458존/3583유닛)를 **유닛별로 펼쳐 3583건 전부** 사용한다.
근거: 존 중심 좌표만 쓰면 존 내 유닛 간 거리가 중앙값 82m, 상위권은 300~582m까지 벌어져
150m/100m 단위 정밀 카운트다운에 오차가 생김.

각 유닛 행에 **부모 존의 `v`(제한속도)와 `d`(사후구간 범위, 기본값 90 — 94%가 이 값)를 그대로 carry-down**.

출력 스키마 (`assets/data/rear_cameras.json`):
```json
[
  {"lat": 37.4912081, "lng": 127.1144657, "speedKmh": 50, "postZoneM": 90},
  ...
]
```

- 변환 스크립트 작성 (Python, 재사용 목적)
- `pubspec.yaml`에 asset 등록
- **완료 기준**: 3583건 생성, `speedKmh`/`postZoneM` 결측 없음, `flutter pub get` PASS

## Phase 1 — 탐지 엔진

`HANDOFF_0724_rear_camera.md` Phase 1 설계 그대로 재사용 (하버사인 + 헤딩 필터 ±70°, `route_progress_provider.dart`의 기존 `_tick()` 패턴).

`RouteProgress` 확장 필드:
```dart
final double distToNextCameraM;   // 다음 카메라까지 거리. 없으면 ∞
final int nextCameraSpeedKmh;
final int nextCameraPostZoneM;    // 해당 카메라의 사후구간 범위 (기본 90)
final bool inPostZone;            // 카메라 통과 후 postZoneM 이내
```

- 게이지 표시 임계값은 **150m** (기존 500m 아님)
- 카메라를 "통과"했는지 판정: 헤딩 기준 카메라가 후방으로 전환되는 시점을 0m로 취급

**완료 기준**: `flutter analyze` PASS, 단위테스트 1건 (정면 150m 접근 탐지, 통과 후 사후구간 진입/이탈)

## Phase 2 — UI (좌측 속도계 변신)

기준 위젯: `_Speedometer` (`nav_screen.dart:2751`), 현재 88×88, `left:12, top: 화면높이*0.30`.

### 2-1. 접근구간 (150m → 0m) — "SEC." 웨지 스타일

참고 이미지: `rear_cctv_3.png` (21→12→11→10→7→6 프레임).

- 150m 진입 시 **심플 스케일업**(200~300ms)으로 88×88 → 176×176 전환. 모프 시퀀스 아님, 위치 고정.
- 붉은 부채꼴이 **남은거리/150m 에 선형 비례**해 검정으로 줄어듦 (원작의 비선형 완급 재현하지 않음).
- **초록 쐐기 + 노란 눈금호는 고정 장식 요소로 포함** (크기 변화 없음, 원본처럼).
- 중앙 숫자 = 남은 거리(m), 정수, 원본과 동일한 7세그먼트 LED 폰트.
- 단위 라벨 "SEC." → **"METER."** 로 교체. **라벨 자체는 깜빡이지 않고, 숫자만 값이 바뀌며 깜빡인다.**
- 나머지 테두리/프레임 장식은 이미지 최대 반영.

### 2-2. 0m 도달 순간 전환 (약 0.3초)

참고 이미지: `rear_cctv_2.png` (6프레임 급속 전환).

- 카메라 지점(0m) 도달 시, 화면이 빠르게(≈0.3초) 빨강으로 가득 차는 플래시성 전환 애니메이션을 넣고 즉시 2-3 사후구간 스타일로 이행.

### 2-3. 사후구간 (0m → postZoneM, 기본 90m) — 점-링 "SLOW" 스타일

참고 이미지: `rear_cctv_1.png` (5,5,3 / 2,2 프레임).

- 중앙 숫자 = postZoneM → 0m 카운트다운 (실거리 기반, 즉 실제 주행에 따라 갱신).
- 내부 원형 텍스트 **"STOP" → "SLOW"** 로 교체 (과속단속카메라 대항 컨셉).
- 둘레 10개 점: **실거리와 무관한 장식용 반시계 스윕** — 전체소등 상태에서 12시 방향부터 반시계로 순차 점등해 1바퀴 완료하는 데 1초, 이게 1사이클. 사후구간을 벗어날 때까지 반복.

### 2-4. 과속 경고 오버레이

- **사후구간(2-3)에서만** 적용. 현재속도(`navState.speedKmh`) > `nextCameraSpeedKmh` 이면 화면 전체에 빨강 opacity 0.3 오버레이, 심장박동처럼 주기적 pulse(scale 또는 opacity 진동).

### 2-5. 구간 종료

- 사후구간을 벗어나면 원래 88×88 속도계로 복귀 (원위치·원크기, 스케일다운 전환).

### 2-6. 레이아웃 처리

- 이벤트 활성 중(접근+사후 전체)에는 속도계 바로 아래 `DaylightBar`를 숨긴다.
- 상단 중앙 `_StructureCurveAlert`(구조물/커브 알림)와 겹치면 기존 정책대로 카메라 알림 우선.

**완료 기준**: 실기기/vGPS 시뮬레이션에서 150m 접근 시 웨지 게이지 등장 → 0m에서 플래시 전환 → 점-링 사후구간 → 정상 속도계 복귀까지 전체 사이클 확인.
