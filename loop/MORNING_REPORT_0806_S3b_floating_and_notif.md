## ✅ 뭐가 됐나 (쉬운 말로)

### 알림 하나로 통일 (결정 A)
전에는 주행을 시작하면 상단에 알림이 **2개**("유루나비 주행 중" + "주행 안내") 떴습니다. 이제 "유루나비 주행 중"을 껐고 **"주행 안내" 1개만** 뜹니다.
- **주의**: 백그라운드에서 위치가 계속 잡히는지는 실기기 확인이 필요합니다(서버에서는 확인 불가). 잘못돼 있으면 홈 화면 상태에서 안내가 몇 분 뒤 멈출 수 있습니다. 아래 "실기기 검증 필요" 참고.

### PIP 폐기 → 플로팅 오버레이로 전환 (결정 A/B 둘 다 아님 → 플로팅)
전에는 홈 버튼을 누르면 우측 하단에 **시스템 PIP(작은 창)**이 떴고, 그 창을 다시 앱으로 되돌리려면 두 번 눌러야 했습니다(창 → 복원 아이콘). 이제 시스템 PIP를 **완전히 없앴고**, 대신 네이버지도/카카오내비처럼 **화면 위에 뜨는 플로팅 아이콘 1개**만 뜹니다.
- 홈 버튼을 누르면 → 카카오톡·인스타 위에 유루나비 아이콘이 뜹니다.
- 아이콘 **한 번만 누르면** 유루나비로 바로 돌아옵니다. 두 번 안 눌러도 됩니다.
- 아이콘에는 다음 회전 화살표와 남은 거리(예: "300m")가 표시됩니다.
- 첫 실행 시 시스템 설정에서 **"다른 앱 위에 표시" 권한**을 켜라는 안내가 나옵니다. 안 켜면 앱은 정상 동작하되 화면 위에 아이콘이 안 뜹니다.

### S3 청크1의 회귀 방지도 지켰습니다
알림창 내리기·스크린샷 같은 잘못된 트리거에서는 플로팅 아이콘이 **뜨지 않습니다**. 오직 홈 버튼처럼 실제로 다른 앱으로 넘어갈 때만 뜹니다. 이걸 자동 테스트 5건으로 못 박아 앞으로 코드가 바뀌어도 이 규칙이 안 깨지도록 했습니다.

## 채택 방식 근거

**패키지(`flutter_overlay_window`) 대신 자체 구현(Kotlin `FloatingOverlayService`) 채택.**

이유: `flutter_overlay_window`는 `FOREGROUND_SERVICE_SPECIAL_USE` 권한과 새 `<service>` 매니페스트 항목을 요구합니다. 지시서의 "새 권한 추가 금지" 가드레일에 걸립니다. Play 심사에서 특수 목적 FGS 사유 소명도 별도 부담이라 자체 구현이 안전합니다.

자체 구현 세부:
- `TYPE_APPLICATION_OVERLAY`(API 26+) / `TYPE_PHONE` 폴백(API<26)
- 72dp 정사각형, 반투명 다크 라운드 배경
- 아이콘 탭 → `FLAG_ACTIVITY_NEW_TASK | SINGLE_TOP | CLEAR_TOP` intent → 앱 즉시 포그라운드
- `START_NOT_STICKY`(오버레이는 시스템 재기동 금지, `NavForegroundService`의 `START_REDELIVER_INTENT`와 구분)
- 드래그 이동은 v1에서 미구현 (스코프 관리, 필요 시 후속)

## ⚠️ 실기기 검증 필요 (마스터 몫)

헤드리스 서버에서는 확인 불가한 항목입니다. 실기기에서 다음을 확인 부탁드립니다:

1. **첫 실행 권한 UX**: 앱 최초 진입 시 "화면 위에 안내 표시 권한이 필요합니다" 다이얼로그 표시 → [설정 열기] 탭 → 시스템 설정에서 유루나비 "다른 앱 위에 표시" 켜기 → 앱 복귀
2. **다른 앱 위 플로팅 표시**: 내비 시작 → 홈 버튼 → 카카오톡 열기 → **유루나비 플로팅 아이콘이 카톡 위에 뜨는지** → 아이콘 1탭 → 유루나비로 즉시 복귀 (2단계 조작 없이)
3. **오버레이 미표시 조건**(중요, S3 회귀 방지): 내비 시작 → 알림창 내림 5회·스크린샷 5회 → 플로팅 아이콘 **표시되지 않음**을 확인
4. **좀비 방지**: 내비 종료 → 오버레이 잔존 없음
5. **백그라운드 위치 fix**: 내비 시작 → 홈 → 5분 방치 → 안내 계속 진행되는지 (알림 A 검증의 핵심)
6. **알림 개수**: 주행 중 상단바에 "주행 안내" 1개만 (`유루나비 주행 중` 안 뜸)

만약 5번(백그라운드 위치)에서 문제 발생 시: `map_providers.dart`의 `foregroundNotificationConfig` 삭제를 되돌리고 알림 방법 C(그대로 둠) 재검토 요청 부탁드립니다.
