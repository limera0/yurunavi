# Google Stitch 디자인 시안 뽑기 — 스크린샷 + 프롬프트 세트

**목적**: 유루나비의 기존 기능/화면 구조는 그대로 유지하면서, Stitch로 9가지 완전히 다른
비주얼 방향의 시안을 뽑아 브랜드 방향성(로드맵 8번 항목)을 정하기 위한 자료.

**사용된 실기기**: M32F 테스트폰(`RZ8RC1N3V9W`), adb로 2026-07-14 방금 실제 앱을 캡처.

---

## 0. 스크린샷 파일 (`loop/stitch_screens/`)

VSCode 파일 탐색기에서 `loop/stitch_screens/` 폴더를 열면 아래 5장이 있습니다. 각 파일을
Stitch에 업로드할 때 "이 이미지처럼 레이아웃/기능을 유지하면서 새 스타일로 다시 그려줘"라는
지시와 함께 씁니다.

| 파일 | 화면 | 반드시 유지해야 할 요소 |
|---|---|---|
| `01_home_map.png` | 홈 지도 화면 | 상단 로고+아이콘 4개(테마/갤러리/히스토리/북마크/설정), 장소 검색바, 지도 위 일출일몰 세로 바(시간+해/달 표시), 우측 하단 현위치·줌+/- 버튼, OSM 어트리뷰션 텍스트 |
| `02_nearby_search_sheet.png` | 주변 탐색 바텀시트 | 상호명 검색창, 카테고리 필터 5개(카페/편의점/주유소/마트/식당) 알약형 버튼 |
| `03_poi_detail_popup.png` | POI 상세 팝업 | 장소명+카테고리, "여기로 안내"(깃발 아이콘)/"닫기"(X 아이콘) 2개 액션 |
| `04_settings.png` | 설정 화면 | 프로필 편집 항목, 지도 표기 언어(라디오 버튼: 한국어/English), 섹션 구분(주행 설정/앱 설정/기타), 이용약관/오픈소스 라이선스 |
| `05_profile_edit.png` | 프로필 편집 화면 | 원형 프로필 사진+편집(연필) 버튼, 닉네임/인스타그램 입력창, "내 바이크" 섹션(+ 추가 버튼, 빈 상태 문구) |

**참고**: 내비게이션(턴바이턴) 화면은 이 세션에서 실기기 GPS/라우팅 흐름이 트리거되지 않아
스크린샷을 못 얻었습니다. 아래 마스터 프롬프트에 이 화면은 텍스트 설명만으로 충분히 상세하게
넣어뒀으니 스크린샷 없이도 진행 가능합니다. 실제 주행 중 캡처가 필요하면 다음에 A34(실주행폰)로
직접 찍어서 추가하는 걸 권장합니다.

## 1. 마스터 프롬프트 (모든 테마 공통 — 매번 앞에 붙이기)

```
너는 모터사이클 투어링 내비게이션 앱 "유루나비(YuruNavi)"의 UI를 리디자인하는 시니어 프로덕트
디자이너다. 아래 기능/제약은 어떤 비주얼 스타일을 선택하든 절대 빠지거나 바뀌면 안 되는
"기능 스펙"이다. 색상·타이포·아이콘 스타일·무드는 완전히 자유롭게 새로 제안해도 좋다
(기존 오렌지/네이비 브랜드 컬러에 얽매이지 마라).

[앱의 정체성]
- 모터사이클 투어러(장거리 라이더)를 위한 내비게이션. 목적지까지 "가장 빠른 길"이 아니라
  "가장 재미있는 길"(굽이진 지방도·시골길)을 우선 추천하는 것이 핵심 차별점.
- 경로를 요청하면 항상 3가지 옵션을 동시에 제시한다: 시골길(scenic, 구불구불한 소로),
  지방도(regional, 중간 성격), 국도(fast, 가장 빠름). 이 3개는 지도 위에서 서로 다른
  색의 선으로 동시에 겹쳐 표시되어야 하고, 사용자가 그중 하나를 골라 출발한다.
- 지도가 화면의 절대적인 주인공이다. 다른 모든 UI(검색바, 버튼, 카드, 바텀시트)는 지도
  위에 반투명/플로팅으로 얹히는 오버레이 형태여야 한다. 화면을 꽉 채우는 전체화면 리스트나
  전통적인 앱바+본문 레이아웃으로 바꾸지 마라(설정/프로필처럼 지도가 필요 없는 화면은 예외).

[화면 목록 — 각각 별도로 리디자인]
1. 홈 지도 화면: 상단에 로고 + 아이콘 버튼 4~5개(테마 전환, 저장한 사진/갤러리, 최근 경로
   히스토리, 즐겨찾기 북마크, 설정), 그 아래 장소/상호명 검색바. 지도 우측에는 오늘의
   일출~일몰 진행을 보여주는 세로형 그라디언트 바(해 아이콘이 현재 시각 위치를 표시,
   위쪽 끝에 일출시각, 아래쪽 끝에 일몰시각 숫자). 지도 우하단에 현재 위치로 이동 버튼과
   확대/축소 버튼. 지도 위에는 항상 켜져 있는 작은 카테고리 핀(편의점/카페/주유소/마트/식당)이
   줌 레벨에 따라 점점 더 많이 나타난다.
2. 주변 탐색 바텀시트: 검색바를 탭하면 지도 아래에서 올라오는 시트. 상호명 검색창 +
   카테고리 알약 버튼 5개(카페/편의점/주유소/마트/식당).
3. POI 상세 팝업: 지도 위 핀을 탭하면 나오는 작은 바텀시트. 장소명, 카테고리, "여기로
   안내" 액션, 닫기 액션.
4. 경로 선택 & 출발 화면: 목적지를 정하면 지도 위 하단에 카드형 바텀시트가 뜬다 —
   시골길/지방도/국도 3개 탭 또는 카드(각각 예상 소요시간, 거리, 색상 뱃지 표시), 그 아래
   "밀어서 출발"하는 슬라이더 형태의 출발 버튼(꾹 누르는 게 아니라 옆으로 슬라이드해야
   출발되는 형태 — 주행 중 실수로 눌리는 걸 방지).
5. 내비게이션(턴바이턴) 화면: 라이딩 중 켜놓고 보는 화면. 상단에 다음 회전 방향 큰 화살표
   아이콘 + 남은 거리("250m 앞 우회전" 같은 큰 텍스트), 지도는 진행 방향이 항상 위를
   향하도록 회전. 화면 한쪽에 남은 거리/도착예정시각을 보여주는 작은 오버레이 카드, 다른
   한쪽에 라이더 프로필 사진이 들어간 플로팅 카드(속도 등 표시). 반드시 3가지 표시 모드로
   각각 디자인할 것:
   (a) 주간 모드 — 밝은 배경, 채도 높은 선명한 색.
   (b) 야간 모드 — 어두운 네이비/차콜 배경, 눈부시지 않게 채도를 낮춘 톤.
   (c) 라이더(직사광선) 모드 — 순수 검정에 가까운 배경 + 매우 굵고 큰 글씨 + 고대비
       네온 색상(핸들바에 거치한 폰을 햇빛 아래서도 읽을 수 있어야 함). 이 모드는 장갑을
       낀 손으로도 오조작 없이 조작 가능해야 하므로 버튼을 크게.
6. 프로필 편집 화면: 원형 프로필 사진(편집 버튼 오버레이), 닉네임, 인스타그램 핸들 입력,
   "내 바이크" 등록 섹션(빈 상태에는 "등록된 바이크가 없습니다" + 추가 버튼).
7. 설정 화면: 프로필 편집 항목, 지도 언어 선택(라디오), 섹션 구분 헤더(주행 설정/앱
   설정/기타), 이용약관·오픈소스 라이선스 링크.

[출력 요청]
각 화면을 모바일(세로, 안드로이드+iOS 모두 무난한 비율) 프레임으로, 실제 그럴듯한 한국
지명/상호명 더미 데이터를 넣어서 그려줘. 최소 홈 지도 화면 + 경로 선택&출발 화면 + 내비게이션
화면(3모드)은 반드시 포함하고, 여유가 되면 나머지도 같은 스타일로 이어서 만들어줘.
```

**팁**: 이 마스터 블록 뒤에 아래 9개 테마 블록 중 하나를 이어 붙이고, 홈 지도 화면
스크린샷(`01_home_map.png`)을 함께 첨부해서 넣으면 첫 화면의 정확도가 크게 올라갑니다.

## 2. 테마별 스타일 블록 (9개)

각 테마마다 **새 Stitch 프로젝트를 따로 만드는 것을 추천**합니다 (한 프로젝트 안에 여러
스타일을 섞으면 Stitch가 앞 스타일을 계속 끌고 와서 결과가 섞입니다). 마스터 프롬프트 +
아래 테마 블록 하나를 이어 붙여서 사용하세요.

### ① 매력적인 (Charming / Delightful)

```
[스타일 방향: 매력적이고 정감 있는(Charming & Delightful)]
전반적으로 "또 열고 싶어지는 앱" 느낌 — 기능성보다 정서적 만족감을 우선한다.
- 색상: 따뜻한 톤 하나(테라코타/살구/허니 옐로 계열 중 택1)를 메인으로, 채도를 살짝
  낮춘 크림/오프화이트 배경과 조합. 원색보다 살짝 톤다운된 "빈티지 크레용" 느낌.
- 타이포: 손글씨 느낌이 살짝 섞인 라운드 산세리프(예: Fredoka, Baloo 스타일). 숫자(거리,
  시간)만 깔끔한 그로테스크로 대비.
- 아이콘/일러스트: 선 굵기가 일정한 라인+필 혼합 아이콘, 지도 마커는 작은 캐릭터화된
  픽토그램(카페 컵이 살짝 웃는 얼굴을 가진다든지).
- 질감: 종이/그레인 텍스처를 배경에 아주 은은하게, 그림자는 하드섀도(오프셋 있는 뚜렷한
  그림자)로 카드에 입체감.
- 참고 무드: 여행 다이어리, 손그림 지도, 감성 다꾸(다이어리 꾸미기) 앱.
- 반드시 피할 것: 차갑고 기업적인 파랑 계열 메인 컬러, 완전 직각 모서리, 그림자 없는
  플랫 디자인.
```

### ② 요새 잘 나가는 (Current Trend / 2026 Modern)

```
[스타일 방향: 요즘 트렌디한 모던 앱(Current-gen Trend)]
2025~2026년 상위 랭크 앱들(피트니스/여행 슈퍼앱 계열)이 쓰는 최신 문법을 적극 반영.
- 레이아웃: 벤토 그리드(Bento Grid) — 홈 화면 카드들을 크기가 다른 사각형 블록으로
  모자이크처럼 배치. 카드 모서리는 매우 큰 라운드(24~32px급).
- 색상: 다크 베이스 + 비비드 그라디언트 메시(보라→핑크→오렌지 같은 2~3색 그라디언트)를
  포인트 요소(버튼, 배지, 진행 바)에만 사용. 배경은 무광 다크 그레이/차콜.
- 재질감: 글래스모피즘(반투명 블러 카드) — 지도 위에 뜨는 시트/카드는 배경이 은은하게
  비치는 유리 질감.
- 타이포: 초대형 볼드 헤드라인(28px+, weight 800), 나머지 텍스트는 확실히 작게 —
  극단적인 크기 대비.
- 인터랙션 느낌: 알약형(pill) 버튼, 떠 있는 하단 네비게이션 바.
- 참고: 최신 Apple Fitness+/Arc 브라우저/Linear 앱 계열의 "테크-프리미엄" 무드.
- 반드시 피할 것: 각진 사각 카드, 파스텔톤, 세리프 폰트, 밋밋한 단색 배경.
```

### ③ 구글 머티리얼 디자인에 충실한 (Material Design 3, faithful)

```
[스타일 방향: Google Material Design 3 표준 준수]
구글의 공식 M3(Material You) 스펙을 최대한 정직하게 따른다 — 창작보다 "정석"이 목표.
- 색상 시스템: 하나의 seed color에서 파생된 M3 tonal palette(Primary/Secondary/Tertiary
  각각 명도 단계별 톤)를 실제로 구성해서 보여줘. 표면은 surface/surfaceContainer 단계별로
  미세하게 다른 명도.
- Elevation: 그림자 대신 M3 방식대로 표면 색조를 한 단계씩 밝게/어둡게 해서 입체감 표현.
- 컴포넌트: FAB(Floating Action Button)는 M3 스펙의 둥근 사각형, 바텀시트는 M3
  standard bottom sheet 스펙(상단 드래그 핸들, 코너 라운드 28px), 필터 칩은 M3
  FilterChip 스타일(선택 시 체크 아이콘 + 톤 변화).
- 타이포: Google Sans 또는 Roboto, M3 type scale(Display/Headline/Title/Body/Label)
  단계를 정확히 구분해서 사용.
- 도형 언어: M3 Expressive의 유기적 블롭(blob) 모양을 지도 위 플로팅 액션 버튼 배경 등에
  포인트로 시도.
- 참고: Google Maps, Gmail, Google 자체 앱들의 최신(2025) 리프레시.
- 반드시 피할 것: iOS 스타일 요소(블러 vibrancy, SF 폰트), 커스텀 임의 색상 시스템,
  M2(구버전 머티리얼)의 진한 퍼플 seed 우려먹기.
```

### ④ Functional한 (Utilitarian / Instrument-panel)

```
[스타일 방향: 기능주의(Functional / Utilitarian)]
"예쁨"보다 "빠르게 읽힘"이 최우선 — 계기판/HUD를 만든다는 마음으로.
- 정보 밀도: 장식 요소를 걷어내고 화면당 실제 데이터(거리/시간/방향/속도)를 최대한 크고
  명확하게. 여백보다 정보량을 우선.
- 색상: 무채색(그레이 스케일) 베이스 + 상태별 의미색 3~4개만(경고=주황, 위험=빨강,
  정상/도착가능=초록) — 장식용 색은 0개.
- 타이포: 모노스페이스 또는 산업용 그로테스크(예: 항공기 계기판, 등산용 GPS 기기 폰트
  느낌), 숫자는 특히 큰 고정폭 숫자.
```

## 3. 실행 순서 제안

1. Stitch에서 **새 프로젝트 9개**를 테마별로 생성 (프로젝트 이름에 테마명 적어두기 —
   예: "YuruNavi - Vespa").
2. 각 프로젝트에서 첫 화면은 `01_home_map.png`를 첨부 + [마스터 프롬프트] + [해당 테마
   블록]을 붙여서 생성.
3. 결과가 마음에 들면 같은 프로젝트 안에서 "방금 스타일 그대로 유지하고, 경로 선택&출발
   화면도 만들어줘" → "내비게이션 화면 주간 모드도" → "야간 모드", "라이더 모드도" 순서로
   이어서 요청 (스타일 일관성이 프로젝트 내에서 자동으로 이어짐).
4. 9개를 다 돌리지 않아도 됨 — 홈 화면만 9개 뽑아서 먼저 훑어보고, 마음에 드는 2~3개만
   골라 나머지 화면까지 확장하는 것을 추천 (무료 크레딧 절약).
5. 마음에 드는 방향이 나오면 스크린샷/Figma 링크를 가져오기 — 이후 실제 Flutter
   구현(`lib/core/theme/palette.dart` 등 토큰 아키텍처에 새 팔레트로 이식)은 별도 세션에서.
