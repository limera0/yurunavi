## 슬라이드별 요약

1. 줌 순서 테스트 — 로딩 5초+ 너무 걸림, 앱 시작 시 백그라운드 프리로딩 필요.
2. 점 정렬이 거리순 아닌 듯(랜덤처럼 보임). 점에 아이콘+이름 없음(네이버지도 참고 이미지 있음).
   점 자체가 터치 안 됨 — 터치 시 정보카드+목적지/경유지 설정 버튼 필요.
   10개 노출 시 우선순위: 주유소>편의점>카페>대형마트>전통시장 요청.
3. 번화가에서 10개 제한 깨지고 수십개 표시되는 버그 있음(에러로 추정).
   카테고리 칩셋이 두 버전으로 뒤섞여 나옴: "카페/편의점/주유소/마트/식당"(신) vs
   "주유소/전통시장/대형마트/식당"(구, 전통시장은 현재 코드에 없어야 함 — 왜 나오는지 재확인 필요).
   10→20개 상향 요청. 화면 전체에 고르게 분포(현재는 중앙에만 몰림) 요청.
4. 리스트 탭 시 확인 없이 바로 목적지로 잡힘 — 카드+버튼(목적지/경유지 설정)으로 바꿔달라 요청.
   목적지/경유지 설정 시 지도 포인터 아래 이름 라벨 필요.
   **카페 칩인데 비카페("할매국물닭발", "신창마을관리사회적협동조합") 섞여나옴 — 카테고리 코드 매핑 버그.**
5. **마트/식당 칩을 눌러도 리스트가 전부 주유소 항목으로 나옴 — 카테고리 필터링이 사실상 깨짐(심각).**
   점 색상(빨/노/초)에 의미 없음, 네이버지도 스타일 아이콘 요청(가스펌프/그릇/포크나이프 예시 첨부됨).
6. 검색 필터링이 앞글자(prefix)만 매칭, 부분 문자열 검색 안 됨.
   검색창 포커스 시 키보드에 바텀시트 가려짐 — 포커스 시 시트가 화면 상단까지 확장돼야 함.
   검색 결과가 "화면 중심" 아닌 "내 위치(GPS)" 중심으로 나옴 — 팬 이동 후 검색 시 문제.
   로딩 속도 느림, 백그라운드 프리페치 요청(데이터 사용량 신경쓰지 말라고 함).
7. **내비게이션(실제 안내) 화면엔 POI 점이 아예 안 뜸 — 가장 심각한 버그로 지목.**
   "주유소/카페 찾기" 핵심 시나리오라 안전 관련. 사용자가 GPS 시뮬레이션으로 우리가 직접
   재현/수정하길 요청, 필요하면 헤드리스 서버에 모니터 연결 제안(집에 여분 모니터 있음).
   속도 프로필 제공: 국도 최고110/평균50, 지방도 최고80/평균40, 시골길 최고60/평균30.
8. 도로 표시(굵기/라벨/번호배지) 만족도 상승 — 남은 부자연스러움(노란/흰 도로 만나는 지점)은
   OSM 구조적 트레이드오프로 수용한다고 함. **긍정 피드백, 추가 조치 불필요.**
9. 코너 진입 "곧 좌/우회전" 음성 타이밍 — "완벽하게 잘 해결됨", 매우 만족. **긍정 피드백.**

10. 3개 경로(시골길/지방도/국도) 비교 — motorway/trunk 회피는 전체적으로 잘 됨(긍정).
    하지만 세 코스가 충분히 차별화 안 됨(시골길·지방도 거리 동일, 불필요한 유턴 포함) —
    costing 가중치를 GPS 시뮬레이션 돌리며 try-and-error로 튜닝 요청.
11. **산길/스위치백 유턴 구간에서 이상한 경로 — 심각.** 반대 방향으로 갔다가 유턴해서
    돌아오는 경로가 시골길·지방도 코스에 공통 발생. 사용자 코멘트: "이런 경로가 나오는
    순간 이 앱의 가치는 밑바닥으로 추락해버림" — 톤이 매우 강함, 우선순위 최상위 후보.
12. 블루투스 음악 재생 중 안내 음성 — 안내 시 덕킹(볼륨 다운)은 잘 됨(긍정). 안내가 끝난
    뒤 볼륨이 원래 크기로 복구되지 않는 버그. **부수 관찰(질문 대상)**: 이 스크린샷의 내비
    화면에 컬러 점(보라/파랑)이 지도 위에 떠 있음 — 13-1b 상시 POI 레이어로 보이는데,
    슬라이드 7의 "내비 화면엔 POI 점이 아예 안 뜸"과 모순돼 보임.
13. 경로 이탈 재탐색 — 선택한 코스 타입 유지하며 자동 재탐색되는 동작 자체는 잘 됨(긍정).
    개선 요청 2건: (a) 이미 지나온 경로 구간을 회색으로 표시, (b) 내비 화면의 경로선
    레이어 순서를 지도 요소(도로번호/가게이름/도로명 라벨) 위가 아니라 아래로 내려서
    라벨을 가리지 않게.
14. 도착 배너 "종료" 버튼 — 목적지 30m 이내+30km/h 이하 조건에서도 화면 하단에 큰 종료
    카드가 안 뜸(네이버지도 대비 회귀 또는 기존 미해결 버그). 신규 요청: 종료 안내 후
    10초 뒤 자동 종료.
15. 목적지 오버슈트 시 자동 재탐색·복귀 안내 — 잘 됨(긍정). 45도 이상 급커브 감속 안내,
    고속도로 출구 지명 안내는 이번 주행에서 확인 못함 — 사용자가 화요일(2026-07-14) 아침
    퇴근길에 확인 예정.
16. **Y자 삼거리에서 좌회전 오안내 — 버그, 좌표 제공됨.** 위치 (37.07016, 127.04945).
    실제로는 우측(서정로)이 직진 코스, 좌측(서정북로)이 좌회전인데 앱이 좌회전 상황에서
    "직진입니다. 차선을 유지하세요"라고 잘못 안내. 진입각으로 보면 우측이 자연스러운
    직진이 맞다는 게 사용자 판단.
